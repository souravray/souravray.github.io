Privacy Policy

Last updated: May 2026

Overview

Redscoop ("we", "our", "the app") is a native macOS menu bar application built and operated by Sourav Ray (raysourav.com). Redscoop is a personal Reddit client that helps users monitor and participate in Reddit conversations relevant to their interests.

Redscoop is a Reddit client application. Reddit data is accessed exclusively through each user's own authenticated Reddit account, for that user's personal participation on Reddit. We do not collect, aggregate, resell, or commercialize Reddit data in any form.

Reddit API Access & OAuth Scopes

Redscoop connects to Reddit using OAuth2 PKCE on behalf of the user. The following scopes are requested:

  • identity — to read the authenticated user's Reddit username
  • read — to fetch posts and comments from subreddits the user chooses to monitor
  • mysubreddits — to list subreddits the user follows, for configuration
  • submit — to post comments that the user has written, reviewed, and explicitly chosen to submit

No other scopes are requested. Redscoop does not access voting, moderation, private messages, mail, or account history.

How Reddit Data Is Used

Reddit content fetched through the API is used solely to:

  • Display threads from subreddits the user has chosen to follow, within the app
  • Match posts against keywords the user has personally configured
  • Provide thread context to the user's local writing assistant to help compose a reply

Reddit data is not transmitted to any external server operated by us. It is not aggregated, indexed, mined, sold, licensed, or used for advertising targeting. All processing occurs on the user's own device.

No Automated Posting

Redscoop does not post to Reddit automatically. Every comment submitted through the app requires the user to:

  • Read the suggested draft
  • Edit the draft in their own words before the submit action is available
  • Explicitly trigger the submission themselves

The app is designed to support genuine, human-authored participation — not to automate or replicate content at scale.

Local Writing Assistance

Redscoop includes an optional writing assistant powered by a locally running language model (via Ollama, running on the user's own machine at localhost). Thread content used to generate draft suggestions is processed entirely on-device and is never transmitted to any cloud AI service by default.

The local model performs inference only. No Reddit content is used to train, fine-tune, or update any machine learning model.

Data Storage & Retention

Redscoop is a local-first application with no backend server. Your Reddit OAuth credentials are stored in the macOS system Keychain on your device. Thread data, keyword configuration, and draft history are stored in a local SQLite database on your Mac.

No Reddit content, credentials, or usage data is stored on servers operated by us.

No User Profiling

Redscoop does not derive, infer, or store sensitive characteristics about Reddit users from the content it processes. Keyword matching operates on post text only and is used solely to surface threads for the authenticated user's own review. No attempt is made to identify, profile, or de-anonymize other Reddit users.

Third-Party Sharing

We do not share your Reddit account data, OAuth tokens, or any Reddit content with third parties for any purpose. The only network communication the app performs is directly between your device and Reddit's official API endpoints.

Revoking Access

You can revoke Redscoop's access to your Reddit account at any time by visiting reddit.com/prefs/apps and removing Redscoop from your authorised applications. You can also disconnect from within the app's settings.

Reddit API Compliance

Redscoop accesses Reddit data in accordance with Reddit's Data API Terms and the Responsible Builder Policy. Your use of Reddit is also governed by Reddit's Privacy Policy.
